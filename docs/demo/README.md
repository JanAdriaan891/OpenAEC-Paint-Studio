# Demonstration preview

[OpenAEC Paint Studio 2026.43.1 — MP4, 55 seconds, 1080p](OpenAEC-Paint-Studio-2026.43.1-demo-preview.mp4)

A real editor recording with Dutch captions and no audio. It demonstrates opening a generated example floor plan, drawing a rectangle, editing text, mirroring, undo, Ctrl+wheel zoom, middle-button panning, Ctrl+A, IFCX saving and PNG export.

The footage was captured in an isolated browser session without user documents. This is the initial preview; it has not been assembled through the requested OpenAEC video repository, whose URL was not available.

The screenshots in the main README show the same example plan. OpenAEC brand assets and template-derived UI retain their existing CC BY-SA 4.0 attribution; see [third-party notices](../../THIRD_PARTY_NOTICES.md).
