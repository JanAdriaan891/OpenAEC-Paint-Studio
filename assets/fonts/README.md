# Renderer fonts

Inter Regular/Semibold and JetBrains Mono Regular are copied unchanged from the pinned OpenAEC Blueprint library. Their SIL OFL 1.1 notices are in `vendor/openaec-ui/licenses/`.

DejaVu Serif Regular/Bold provide the serif option independently of the host's installed fonts. See `DejaVu-LICENSE.txt` (Bitstream Vera license and public-domain DejaVu changes).
